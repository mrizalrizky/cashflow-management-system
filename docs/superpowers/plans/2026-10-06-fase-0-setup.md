# Fase 0: Setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A runnable monorepo: PostgreSQL in Docker, a NestJS API with the full database schema, seed data and a `/api/v1/health` endpoint, and a Vue web app that shows whether the API is reachable.

**Architecture:** npm workspaces with `apps/api` (NestJS 12, ESM, Prisma 7 with the `pg` driver adapter) and `apps/web` (Vue 3 + Vite). The API owns the database through Prisma migrations. The web app talks to the API through the Vite dev proxy on `/api`.

**Tech Stack:** Node 24, NestJS 12, Prisma 7.10.0, PostgreSQL 16, Vitest, oxlint, Vue 3.5, Vite 8, Pinia, Vue Router, PrimeVue 4.5.5, Tailwind CSS 4.

**Spec:** `docs/superpowers/specs/2026-10-06-cashflow-mvp-design.md` (base document: `implementation-plan-cashflow-mvp.md`). Read both before starting. Where they conflict, the spec wins.

This plan covers Fase 0 only. Fase 1 to 6 each get their own plan after this one passes.

## Global Constraints

- Prisma model fields are `snake_case`, identical to column names. No field-level `@map`.
- Model names are `PascalCase`, mapped to plural `snake_case` tables with `@@map`. Enum types are mapped to `snake_case` with `@@map`; enum values stay `UPPER_CASE`.
- Index and constraint names: `idx_<table>_<column>` and `uq_<table>_<column>`.
- Money is integer rupiah: `BigInt` in Prisma, `bigint` in TypeScript, serialised as a string in JSON. Never `number`.
- API JSON properties are `camelCase`. All routes live under `/api/v1`.
- All schema changes go through Prisma migrations. Never edit the database by hand.
- Pin `prisma`, `@prisma/client` and `@prisma/adapter-pg` to exactly `7.10.0` (npm's `latest` tag is an 8.0 release candidate).
- Pin `primevue` to `4.5.5` and `@primeuix/themes` to `2.0.3`. Do not install PrimeVue 5 (non-MIT licence).
- The API is ESM (`"type": "module"`): every relative import ends in `.js`.
- User-facing text and error messages are in Indonesian.
- No secrets in the repo. The dev database password in `docker-compose.dev.yml` is a local-only default.
- Storage is local disk, state is Pinia, tests are Vitest. No MinIO, NgRx, Angular or Jest.
- Do not build anything outside Fase 0 (no auth, no CRUD endpoints).

## Review Focus

- **e2e tests pointed at a non-test database:** the e2e suite truncates tables, so it must refuse to run unless the database name ends in `_test`. Pinned in Task 3.
- **Seed run a second time:** no duplicate accounts or categories, and the admin's password is not reset to the seed value. Pinned in Task 4.
- **Missing or malformed environment:** an absent or empty `DATABASE_URL`, or a non-numeric `PORT`, stops startup with a message naming the variable. Pinned in Task 2.
- **Database down while the API is up:** `/api/v1/health` answers 503 with a JSON body instead of hanging or returning 500. Pinned in Task 5.
- **API unreachable from the browser:** the home page shows "API tidak terhubung" instead of staying on the loading state or rendering blank. Pinned in Task 6.

`apps/api/src/config/env.validation.ts`:

```ts
import { plainToInstance, Type } from 'class-transformer';
import { IsIn, IsInt, IsNotEmpty, IsString, Max, Min, validateSync } from 'class-validator';

export class EnvVars {
  @IsIn(['development', 'test', 'production'])
  NODE_ENV: string = 'development';

  @Type(() => Number)
  @IsInt()
  @Min(1)
  @Max(65535)
  PORT: number = 3000;

  @IsString()
  @IsNotEmpty()
  DATABASE_URL: string;
}

export function validateEnv(raw: Record<string, unknown>): EnvVars {
  const env = plainToInstance(EnvVars, raw);
  const errors = validateSync(env);
  if (errors.length > 0) {
    const detail = errors
      .map((e) => `${e.property}: ${Object.values(e.constraints ?? {}).join(', ')}`)
      .join('; ');
    throw new Error(`Konfigurasi environment tidak valid. ${detail}`);
  }
  return env;
}
```

export function installBigIntJson(): void {
  (BigInt.prototype as unknown as { toJSON: () => string }).toJSON = function (this: bigint) {
    return this.toString();
  };
}

/** e2e mengosongkan tabel, jadi hanya boleh jalan di database yang namanya diakhiri `_test`. */
export function assertTestDatabaseUrl(url: string | undefined): string {
  if (!url) {
    throw new Error('DATABASE_URL untuk e2e belum diisi');
  }
  const dbName = new URL(url).pathname.replace(/^\//, '');
  if (!dbName.endsWith('_test')) {
    throw new Error(`e2e menolak jalan di database "${dbName}": nama harus diakhiri _test`);
  }
  return url;
}

import argon2 from 'argon2';
import type { PrismaClient } from '../generated/prisma/client.js';

export interface SeedOptions {
  adminName?: string;
  adminEmail?: string;
  adminPassword?: string;
}

const ACCOUNTS = [
  { name: 'Kas Kecil', type: 'CASH' },
  { name: 'Rekening Bank Utama', type: 'BANK' },
] as const;

const CATEGORIES_IN = ['DP Proyek', 'Termin Proyek', 'Pelunasan Proyek', 'Pendapatan Lain'];

const CATEGORIES_OUT = [
  'Material',
  'Upah Tukang',
  'Subkontraktor',
  'Peralatan',
  'Transportasi',
  'Perizinan',
  'Gaji Staf',
  'Sewa Kantor',
  'Utilitas',
  'Pajak',
  'Operasional Lain',
];

const CATEGORIES = [
  ...CATEGORIES_IN.map((name) => ({ name, type: 'IN', is_system: false }) as const),
  ...CATEGORIES_OUT.map((name) => ({ name, type: 'OUT', is_system: false }) as const),
  { name: 'Transfer Masuk', type: 'IN', is_system: true } as const,
  { name: 'Transfer Keluar', type: 'OUT', is_system: true } as const,
];

/** Aman dijalankan berulang: tidak menggandakan data dan tidak menimpa password admin. */
export async function seedDatabase(prisma: PrismaClient, options: SeedOptions): Promise<void> {
  const email = options.adminEmail?.trim().toLowerCase();
  if (!email) {
    throw new Error('SEED_ADMIN_EMAIL wajib diisi');
  }
  const password = options.adminPassword ?? '';
  if (password.length < 8) {
    throw new Error('SEED_ADMIN_PASSWORD wajib diisi, minimal 8 karakter');
  }

  const existingAdmin = await prisma.user.findUnique({ where: { email } });
  if (!existingAdmin) {
    await prisma.user.create({
      data: {
        name: options.adminName?.trim() || 'Administrator',
        email,
        password_hash: await argon2.hash(password),
        role: 'SUPER_ADMIN',
        must_change_password: true,
      },
    });
  }

  for (const account of ACCOUNTS) {
    const existing = await prisma.account.findFirst({ where: { name: account.name } });
    if (!existing) {
      await prisma.account.create({ data: account });
    }
  }

  for (const category of CATEGORIES) {
    await prisma.category.upsert({
      where: { name_type: { name: category.name, type: category.type } },
      update: {},
      create: category,
    });
  }
}

export type HealthState = 'up' | 'down'

export async function fetchHealth(fetchFn: typeof fetch = fetch): Promise<HealthState> {
