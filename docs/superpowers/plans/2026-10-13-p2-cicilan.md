# P2 Cicilan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Track several running installments (cicilan) whose progress comes from expense transactions linked to them, chosen in the transaction form whenever the category is flagged "Kategori cicilan".

**Architecture:** A new `installments` table and API module; `categories.is_installment` and `transactions.installment_id` link them. Progress, due count and status are never stored: one pure module (`installment-progress.ts`) computes them from `start_month`, `months`, the number of non-VOID linked transactions and the current Jakarta month. The transaction service enforces the link rules while holding a row lock on the installment, so two payments for the last month cannot both succeed. The web app gets a Cicilan page (summary, list, detail, form), a category checkbox, and a "Cicilan yang dibayar" dropdown in the transaction form.

**Tech Stack:** NestJS 12 (ESM), Prisma 7 + PostgreSQL, Vitest + supertest; Vue 3.5, Pinia, PrimeVue 4.5, Tailwind 4, Vitest + jsdom, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-12-personal-edition-design.md`, section "P2: Cicilan" (on top of `docs/superpowers/specs/2026-10-06-cashflow-mvp-design.md`).

## Global Constraints

- Prisma fields, columns, tables, enums and indexes are `snake_case`; models `PascalCase` with `@@map`; no `@map` on fields. All schema changes through a Prisma migration.
- JSON properties are `camelCase`; mapping happens in response mappers.
- Money is integer rupiah: `bigint` in the data layer, digit strings in JSON. Never `number` for amounts.
- Every change to installments, categories and transactions writes its audit log in the same database transaction.
- No hard delete of transactions. (Installments may be deleted, only while nothing is linked — rule 7.)
- API ESM: every relative import ends in `.js`.
- Months: `start_month` is stored as the first day of the month (`DATE`); JSON uses `YYYY-MM`. "Bulan berjalan" is the current month in Asia/Jakarta.
- `months` is 1 to 120. `monthly_amount` > 0, at most 13 digits (same as transaction amounts).
- Status labels: `NOT_STARTED` "Belum mulai", `ON_TRACK` "Berjalan", `BEHIND` "Tertinggal", `PAID_OFF` "Lunas".
- Out of scope: due-date reminders, interest, schedules per term, CSV export columns for installments.
- Tests that touch the database only run against a database whose name ends in `_test`; never run two DB test runs at once.

## Review Focus

1. **Two payments for the last remaining month saved at the same time:** exactly one succeeds; the other gets the "sudah lunas" field error, never 3/2. Test in Task 4 (parallel requests).
2. **Jakarta month boundary:** at 31 Oct 23:30 WIB (16:30Z) the current month is October; at 1 Nov 00:30 WIB (31 Oct 17:30Z) it is November, so "seharusnya" and the status change at Jakarta midnight, not UTC midnight. Test in Task 1.
3. **Editing a transaction already linked to a paid-off installment:** changing only its amount or description succeeds; moving another transaction onto that installment is refused. Test in Task 4. The dropdown still shows the linked, paid-off installment when editing. Test in Task 6.
4. **Lowering `months` to the number already paid:** allowed, and the installment becomes Lunas; one below is refused with a field error naming the count. Test in Task 2.
5. **Voiding a payment of a paid-off installment:** the installment reopens (status no longer Lunas) and accepts a new payment. Test in Task 4.

const MONTH_PATTERN = /^(\d{4})-(0[1-9]|1[0-2])$/;

/** Bulan kalender di JSON: `YYYY-MM`, tahun 1900 sampai 2999. */
export function isCalendarMonth(value: unknown): value is string {
  if (typeof value !== 'string') return false;
  const match = MONTH_PATTERN.exec(value);
  if (!match) return false;
  const year = Number(match[1]);
  return year >= MIN_YEAR && year <= MAX_YEAR;
}

export function IsCalendarMonth(options?: ValidationOptions): PropertyDecorator {
  return (target, propertyName) => {
    registerDecorator({
      name: 'isCalendarMonth',
      target: target.constructor,
      propertyName: String(propertyName),
      options: { message: '$property harus berupa bulan berformat YYYY-MM', ...options },
      validator: { validate: isCalendarMonth },
    });
  };
}

/** Bulan disimpan sebagai tanggal hari pertamanya (kolom DATE). */
export function parseCalendarMonth(month: string): Date {
  return parseCalendarDate(`${month}-01`);
}

export function formatCalendarMonth(value: Date): string {
  return formatCalendarDate(value).slice(0, 7);
}

/** Bulan berjalan menurut kalender Jakarta, sebagai `YYYY-MM`. */
export function currentMonthInJakarta(now: Date = new Date()): string {
  return todayInJakarta(now).slice(0, 7);
}

function monthIndex(month: string): number {
  return Number(month.slice(0, 4)) * 12 + Number(month.slice(5, 7)) - 1;
}

function fromMonthIndex(index: number): string {
  const year = Math.floor(index / 12);
  return `${String(year).padStart(4, '0')}-${String((index % 12) + 1).padStart(2, '0')}`;
}

export function addMonths(month: string, count: number): string {
  return fromMonthIndex(monthIndex(month) + count);
}

/** Selisih bulan `to - from`, mis. Nov 2026 ke Feb 2027 = 3. */
export function monthsBetween(from: string, to: string): number {
  return monthIndex(to) - monthIndex(from);
}
```

import { addMonths, monthsBetween } from '../common/calendar-date.js';

export type InstallmentStatus = 'NOT_STARTED' | 'ON_TRACK' | 'BEHIND' | 'PAID_OFF';

export interface InstallmentProgress {
  /** Bulan terakhir, `YYYY-MM`; dihitung, tidak disimpan. */
  endMonth: string;
  /** Transaksi tertaut yang tidak VOID. */
  paid: number;
  /** Bulan dari bulan mulai sampai bulan berjalan, keduanya ikut, dibatasi 0 sampai `months`. */
  due: number;
  /** `due - paid` bila tertinggal, selain itu 0. */
  behindMonths: number;
  status: InstallmentStatus;
  /** Bulan berjalan berada di antara bulan mulai dan bulan selesai. */
  coversMonth: boolean;
}

/** Satu-satunya tempat kemajuan cicilan dihitung (spec P2, aturan 2 sampai 5). */
export function progressOf(
  input: { startMonth: string; months: number; paid: number },
  currentMonth: string,
): InstallmentProgress {
  const endMonth = addMonths(input.startMonth, input.months - 1);
  const elapsed = monthsBetween(input.startMonth, currentMonth) + 1;
  const due = Math.min(Math.max(elapsed, 0), input.months);
  const notStarted = monthsBetween(input.startMonth, currentMonth) < 0;
  const status: InstallmentStatus = notStarted
    ? 'NOT_STARTED'
    : input.paid >= input.months
      ? 'PAID_OFF'
      : input.paid < due
        ? 'BEHIND'
        : 'ON_TRACK';
  return {
    endMonth,
    paid: input.paid,
    due,
    behindMonths: status === 'BEHIND' ? due - input.paid : 0,
    status,
    coversMonth: !notStarted && monthsBetween(currentMonth, endMonth) >= 0,
  };
}
```

import type { Db } from '../database/db.js';
import type { Installment, Prisma } from '../generated/prisma/client.js';

/**
 * Mengunci baris cicilan sampai transaksi database selesai. Semua yang menghitung pembayaran
 * lalu menulis (bayar, ubah jumlah bulan, hapus) mengambil kunci ini lebih dulu, supaya dua
 * pembayaran bulan terakhir tidak sama-sama lolos.
 */
export async function lockInstallment(
  tx: Prisma.TransactionClient,
  id: string,
): Promise<Installment | null> {
  const rows = await tx.$queryRaw<{ id: string }[]>`SELECT id FROM installments WHERE id = ${id} FOR UPDATE`;
  return rows.length === 0 ? null : tx.installment.findUnique({ where: { id } });
}

/** Pembayaran yang dihitung: transaksi tertaut yang tidak VOID, selain transaksi yang dikecualikan. */
export function paidCount(db: Db, id: string, exceptTransactionId?: string): Promise<number> {
  return db.transaction.count({
    where: {
      installment_id: id,
      status: { not: 'VOID' },
      id: exceptTransactionId ? { not: exceptTransactionId } : undefined,
    },
  });
}

import { ConflictException, Injectable, NotFoundException } from '@nestjs/common';
import { AuditService } from '../audit/audit.service.js';
import type { AuthUser } from '../auth/auth.types.js';
import { currentMonthInJakarta, parseCalendarMonth } from '../common/calendar-date.js';
import { fromMoney, toMoney } from '../common/money.js';
import { validationFailed } from '../common/validation.js';
import { PrismaService } from '../database/prisma.service.js';
import type { Installment, Prisma } from '../generated/prisma/client.js';
import {
  toTransactionResponse,
  TRANSACTION_INCLUDE,
} from '../transactions/transaction.mapper.js';
import type {
  CreateInstallmentDto,
  ListInstallmentsQueryDto,
  UpdateInstallmentDto,
} from './dto/installment.dto.js';
import { lockInstallment, paidCount } from './installment-lock.js';
import {
  InstallmentDetailResponse,
  InstallmentListResponse,
  progressFor,
  toInstallmentResponse,
  toInstallmentSnapshot,
  InstallmentResponse,
} from './installment.mapper.js';

const ENTITY = 'installment';

function notFound(): NotFoundException {
  return new NotFoundException('Cicilan tidak ditemukan');
}

/** Catatan kosong disimpan sebagai null. */
function notesOf(value: string | null | undefined): string | null | undefined {
  if (value === undefined) return undefined;
  return value === null || value === '' ? null : value;
}

@Injectable()
export class InstallmentsService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly audit: AuditService,
  ) {}

  /** Cicilan jumlahnya sedikit: semuanya dimuat, ringkasan selalu atas semuanya. */
  async list(query: ListInstallmentsQueryDto): Promise<InstallmentListResponse> {
    const month = currentMonthInJakarta();
    const installments = await this.prisma.installment.findMany({ orderBy: [{ name: 'asc' }, { id: 'asc' }] });
    const counts = await this.paidCounts(installments.map((i) => i.id));
    const all = installments.map((installment) =>
      toInstallmentResponse(installment, progressFor(installment, counts.get(installment.id) ?? 0, month)),
    );

    const unpaid = all
      .filter((item) => item.status === 'BEHIND')
      .map((item) => ({
        id: item.id,
        name: item.name,
        months: item.behindMonths,
        amount: fromMoney(BigInt(item.behindMonths) * toMoney(item.monthlyAmount)),
      }));
    const activeMonthlyTotal = installments
      .filter((installment) => progressFor(installment, 0, month).coversMonth)
      .reduce((sum, installment) => sum + installment.monthly_amount, 0n);

    return {
      items: all.filter((item) =>
        query.status === undefined ? true : query.status === 'PAID_OFF' ? item.status === 'PAID_OFF' : item.status !== 'PAID_OFF',
      ),
      summary: {
        month,
        activeMonthlyTotal: fromMoney(activeMonthlyTotal),
        unpaid,
        unpaidTotal: fromMoney(unpaid.reduce((sum, item) => sum + toMoney(item.amount), 0n)),
      },
    };
  }

  async get(id: string): Promise<InstallmentDetailResponse> {
    const installment = await this.prisma.installment.findUnique({ where: { id } });
    if (!installment) throw notFound();
    const transactions = await this.prisma.transaction.findMany({
      where: { installment_id: id },
      include: TRANSACTION_INCLUDE,
      orderBy: [{ transaction_date: 'desc' }, { created_at: 'desc' }, { id: 'desc' }],
    });
    const paid = transactions.filter((t) => t.status !== 'VOID').length;
    return {
      ...toInstallmentResponse(installment, progressFor(installment, paid, currentMonthInJakarta())),
      transactions: transactions.map(toTransactionResponse),
    };
  }

  create(actor: AuthUser, dto: CreateInstallmentDto, ip: string | null): Promise<InstallmentResponse> {
    return this.prisma.$transaction(async (tx) => {
      const installment = await tx.installment.create({
        data: {
          name: dto.name,
          monthly_amount: toMoney(dto.monthlyAmount),
          start_month: parseCalendarMonth(dto.startMonth),
          months: dto.months,
          notes: notesOf(dto.notes) ?? null,
        },
      });
      await this.audit.log(tx, {
        userId: actor.id,
        action: 'CREATE',
        entityType: ENTITY,
        entityId: installment.id,
        after: toInstallmentSnapshot(installment),
        ip,
      });
      return this.respond(tx, installment);
    });
  }

  update(actor: AuthUser, id: string, dto: UpdateInstallmentDto, ip: string | null): Promise<InstallmentResponse> {
    return this.prisma.$transaction(async (tx) => {
      const before = await lockInstallment(tx, id);
      if (!before) throw notFound();
      if (dto.months !== undefined) {
        const paid = await paidCount(tx, id);
        if (dto.months < paid) {
          throw validationFailed([
            { field: 'months', messages: [`Jumlah bulan tidak boleh kurang dari ${paid} pembayaran yang sudah tercatat`] },
          ]);
        }
      }
      const installment = await tx.installment.update({
        where: { id },
        data: {
          name: dto.name,
          monthly_amount: dto.monthlyAmount === undefined ? undefined : toMoney(dto.monthlyAmount),
          start_month: dto.startMonth === undefined ? undefined : parseCalendarMonth(dto.startMonth),
          months: dto.months,
          notes: notesOf(dto.notes),
        },
      });
      await this.audit.log(tx, {
        userId: actor.id,
        action: 'UPDATE',
        entityType: ENTITY,
        entityId: id,
        before: toInstallmentSnapshot(before),
        after: toInstallmentSnapshot(installment),
        ip,
      });
      return this.respond(tx, installment);
    });
  }

  delete(actor: AuthUser, id: string, ip: string | null): Promise<void> {
    return this.prisma.$transaction(async (tx) => {
      const before = await lockInstallment(tx, id);
      if (!before) throw notFound();
      if ((await tx.transaction.count({ where: { installment_id: id } })) > 0) {
        throw new ConflictException('Cicilan sudah punya pembayaran tercatat, jadi tidak bisa dihapus');
      }
      await tx.installment.delete({ where: { id } });
      await this.audit.log(tx, {
        userId: actor.id,
        action: 'DELETE',
        entityType: ENTITY,
        entityId: id,
        before: toInstallmentSnapshot(before),
        ip,
      });
    });
  }

  private async respond(tx: Prisma.TransactionClient, installment: Installment): Promise<InstallmentResponse> {
    const paid = await paidCount(tx, installment.id);
    return toInstallmentResponse(installment, progressFor(installment, paid, currentMonthInJakarta()));
  }

  private async paidCounts(ids: string[]): Promise<Map<string, number>> {
    const groups = await this.prisma.transaction.groupBy({
      by: ['installment_id'],
      where: { installment_id: { in: ids }, status: { not: 'VOID' } },
      _count: { _all: true },
    });
    return new Map(groups.map((g) => [g.installment_id!, g._count._all]));
  }
}

```ts
import { lockInstallment, paidCount } from '../installments/installment-lock.js';
import { validationFailed } from '../common/validation.js';
import type { Category, Prisma, TxType } from '../generated/prisma/client.js';

function linkError(message: string) {
  return validationFailed([{ field: 'installmentId', messages: [message] }]);
}

/**
 * Menentukan cicilan yang dibayar transaksi ini setelah perubahan (spec P2, aturan 1, 3, 9):
 * kategori cicilan wajib bertaut; kategori lain tidak boleh, dan tautan lama dilepas.
 * Cicilan yang dipilih dikunci lebih dulu, supaya hitungan "sudah lunas" tidak berbalapan.
 */
export async function resolveInstallmentLink(
  tx: Prisma.TransactionClient,
  input: {
    type: TxType;
    category: Category;
    /** Dari permintaan: undefined = tidak diubah. */
    requested: string | null | undefined;
    /** Tautan yang tersimpan sekarang; null untuk transaksi baru. */
    current: string | null;
    transactionId?: string;
  },
): Promise<string | null> {
  const needsLink = input.type === 'OUT' && input.category.is_installment;
  if (!needsLink) {
    if (input.requested) throw linkError('Hanya transaksi berkategori cicilan yang bisa ditautkan ke cicilan');
    return null;
  }

  const chosen = input.requested === undefined ? input.current : input.requested;
  if (!chosen) throw linkError('Pilih cicilan yang dibayar');

  const installment = await lockInstallment(tx, chosen);
  if (!installment) throw linkError('Cicilan tidak ditemukan');
  // Transaksi yang sudah tertaut ke cicilan ini tetap boleh diubah walau cicilannya lunas.
  if (chosen !== input.current) {
    const paid = await paidCount(tx, chosen, input.transactionId);
    if (paid >= installment.months) throw linkError('Cicilan ini sudah lunas');
  }
  return chosen;
}
```

import { formatRupiah } from './money'

const STATUS_LABELS: Record<InstallmentStatus, string> = {
  NOT_STARTED: 'Belum mulai',
  ON_TRACK: 'Berjalan',
  BEHIND: 'Tertinggal',
  PAID_OFF: 'Lunas',
}

export function installmentStatusLabel(status: InstallmentStatus): string {
  return STATUS_LABELS[status]
}

export const INSTALLMENT_STATUS_SEVERITY: Record<InstallmentStatus, 'secondary' | 'info' | 'warn' | 'success'> = {
  NOT_STARTED: 'secondary',
  ON_TRACK: 'info',
  BEHIND: 'warn',
  PAID_OFF: 'success',
}

export const MONTHS_MIN = 1
export const MONTHS_MAX = 120

/** Bulan selesai, dihitung seperti API: `start + months - 1`. */
export function endMonthOf(startMonth: string | null, months: number): string | null {
  if (!startMonth || !Number.isInteger(months) || months < MONTHS_MIN) return null
  const index = Number(startMonth.slice(0, 4)) * 12 + Number(startMonth.slice(5, 7)) - 1 + months - 1
  return `${Math.floor(index / 12)}-${String((index % 12) + 1).padStart(2, '0')}`
}

export function progressText(installment: { paid: number; months: number }): string {
  return `${installment.paid}/${installment.months}`
}

/** "Nama · nominal · kemajuan", untuk dropdown di form transaksi. */
export function installmentOptionLabel(installment: {
  name: string
  monthlyAmount: string
  paid: number
  months: number
}): string {
  return `${installment.name} · ${formatRupiah(installment.monthlyAmount)} · ${progressText(installment)}`
}
